# temperature_converter
This is a simple temperature converter website created as part of my internship task. It allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Input validation
- Error message for invalid input
- Absolute zero validation
- Clear conversion results
- Reset button
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
